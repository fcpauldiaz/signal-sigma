# Signal Sigma mobile

register: product

## Product Purpose

Personal trading desk on a phone. Same Signal Sigma / Tradier book as the web desk: equity, positions, pending orders, realized P&L, and the Wednesday rebalance / place-orders jobs.

## Users

The operator of this desk. One person, already fluent in paper vs live, ownership-price eligibility, and Coolify cron.

## Product Principles

- The book is the product. Equity is the primary readout; everything else is context.
- Paper is the default mood. Live is visually marked and confirmed before it mutates.
- Never invent a metric. Missing values render as —.
- Match the web desk's Terminal workbench. This is a companion, not a new brand.

## Tone

Technical. Phosphor on near-black. Short labels. No marketing copy.

## Anti-references

Navy-and-gold fintech. Glassmorphism. Identical icon+title cards. Hero-metric SaaS dashboards. Gradient text.
